# The Loper Residence — version 1
Open index.html for a local preview. For iPad installation, create a public GitHub repository named loper-residence, upload the all application files to its root, and enable Settings > Pages > Deploy from a branch > main / root. Open the resulting HTTPS URL in Safari and choose Share > Add to Home Screen. Do not upload household backups or private information to the repository.

This version uses local browser storage, not shared accounts or a cloud database. The calendar, Ring and media links open external services; no live feeds or sync are implemented. Timers require the dashboard to remain active. Test on your iPad before relying on alerts. Export backups in Settings. No paid service is required for the dashboard itself.
